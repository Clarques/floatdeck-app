# 🚀 FloatDeck - Workflow Optimization & AI Integration

This project is not just a static Landing Page; it is the result of a **Product Discovery** process and **AI Orchestration** (via Google Gemini) focused on **Operational Efficiency** and reducing cognitive fatigue.

FloatDeck was designed with a premium interface and an architecture geared towards high conversion, simulating the experience of a real corporate software.

## 🧠 Strategic Vision & Highlights

- **Clean Front-End Architecture:** Developed purely with Semantic HTML5, CSS3, and Vanilla JavaScript, ensuring ultra-fast loading times without relying on heavy libraries.
- **Lead Pipeline Integration (AJAX/Fetch):** The lead capture form is directly integrated into the CRM (Brevo) via a secure Endpoint. It uses asynchronous interception for data submission without reloading the page, retaining user attention (Frictionless UX).
- **Dynamic Internationalization (i18n):** The system features instant language switching (English, Portuguese, Spanish) within the DOM, seamlessly updating titles, placeholders, and conversion buttons.
- **Premium UI/UX:** Implementation of CSS variables for Dark Mode management, Glassmorphism, and full responsiveness. Avatars and mockups follow a 1:1 ratio and ideal proportions for Retina displays.
- **Compliance and Security:** Legal texts drafted with LGPD (General Data Protection Law) and Chrome Web Store guidelines in mind (Data Minimization), demonstrating maturity in Data Governance.

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, CSS3 (Custom Properties/Flexbox/Grid), JavaScript (ES6+).
- **Marketing & Data:** Brevo, Getform Endpoint.
- **AI Tools:** Technical orchestration of agents via Gemini 3 and advanced prompt engineering for photorealistic mockups (Midjourney/Firefly).
- **Version Control:** Git & GitHub Flow.
